# Точка Сэма

Сайт выездного кейтеринга с приготовлением на живом огне.

## Запуск

```sh
cd site
python3 serve.py
```

Открыть http://127.0.0.1:4174. Готовый статический сайт находится в `site/dist/`. Сборка и установка зависимостей не требуются.

Галереи автоматически переключаются; первый экран использует последовательность кадров, связанную с прокруткой. Фото еды и мероприятий разделены. Основной шрифт заголовков — Roboto Slab.

Форма и виджет готовят контакт для копирования. Отправка менеджеру не подключена. Выбор фотографий записан в `site/photo-selection.json`, сведения об источниках — в `site/PHOTO-CREDITS.md`.
